GRANNY MODES LIST - GITHUB PAGES FILES

This folder contains the complete static site package:
- index.html: the website GitHub Pages opens
- index.txt: matching plain-text copy of the website code
- Banner.png: site banner image
- favicon.png: browser tab icon

PUBLISH FOR FREE WITH GITHUB PAGES
1. On GitHub, create a PUBLIC repository named YOUR-GITHUB-USERNAME.github.io.
2. Extract this package if you are using the ZIP, then upload the files in this folder to the top level of the repository.
3. Open the repository Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch. Select main and /(root), then Save.
5. Visit https://YOUR-GITHUB-USERNAME.github.io after GitHub finishes publishing.

The repository must use the exact username.github.io name so the site's /favicon.png path works as-is. Keep the banner and favicon beside index.html. The website continues using the existing Supabase project; this package does not modify the database and does not require new SQL.
