GRANNY MODES LIST - GITHUB PAGES FILES

Upload the CONTENTS of this folder directly into the top level (root) of your GitHub repository. Do not upload this folder itself or the ZIP as the only repository file.

Files:
- index.html: the website GitHub Pages opens
- index.txt: matching plain-text copy of the website code
- Banner.png: site banner image
- favicon.png: browser tab icon

PUBLISH WITH GITHUB PAGES
1. Extract the ZIP on your computer.
2. In your GitHub repository, choose Add file > Upload files.
3. Select the files inside the extracted folder (index.html, index.txt, Banner.png, favicon.png, and this README.txt) and upload them to the repository root. Commit directly to main.
4. Open Settings > Pages. Choose Deploy from a branch, select main and /(root), then Save.
5. For a repository named GrannyModesList, the published URL is https://YOUR-GITHUB-USERNAME.github.io/GrannyModesList/ .

Keep index.html, Banner.png, and favicon.png together in the repository root. The website continues using the existing Supabase project; this package does not modify the database and does not require new SQL.
